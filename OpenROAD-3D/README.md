# OpenROAD-3D Company Evaluation Flow

This directory evaluates 3D placement results generated by the company placer. The placer emits separate top and bottom DEF files; OpenROAD-3D merges them and runs the existing backend stages.

## Start the eval container

From the repository root, install/start Docker and load the eval image as described in `doc/DEPLOY_README.zh-CN.md`. Then run:

```bash
cd OpenROAD-3D
COMPANY_PLACER_OUTPUTS=/root/Workspace/freePartitioner/output_openroad \
  ./start_docker_eval.sh
```

The input directory is mounted read-only at `/workspace/company-input`.

## Convert a DEF pair

Inside the eval container:

```bash
cd /workspace/OpenROAD-3D/flow
python3 util/convert_company_3d_def.py \
  --top /workspace/company-input/swerv_wrapper_top.def \
  --bottom /workspace/company-input/swerv_wrapper_bot.def \
  --output /tmp/swerv_wrapper.merged.def
```

## Run backend evaluation

```bash
./run_company_3d.sh swerv_wrapper \
  /workspace/company-input/swerv_wrapper_top.def \
  /workspace/company-input/swerv_wrapper_bot.def
```

Supported aliases:

```text
ariane  bp  swerv_wrapper  tinyRocket
```

Add `--hotspot` to run thermal evaluation.

Company-specific configuration files are under:

```text
flow/designs/nangate45_3D/<design>/config_company.mk
```

The detailed CentOS WSL deployment and CodeHub workflow is documented in `doc/DEPLOY_README.zh-CN.md`.
